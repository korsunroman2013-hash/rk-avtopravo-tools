Сервис предоставляет информационные инструменты и автоматизированные шаблоны для подготовки проектов заявлений, обращений и иных документов по вопросам автомобильного права.

3. Обязанности пользователя

Пользователь вводит достоверные сведения, не использует сервис для противоправных целей и не вводит персональные данные третьих лиц без законного основания. При подготовке документа от имени другого лица пользователь самостоятельно отвечает за наличие соответствующих полномочий.
