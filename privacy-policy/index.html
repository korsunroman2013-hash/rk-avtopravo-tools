2. Принципы работы сервиса

Генераторы построены по принципу минимизации данных. Сведения, которые пользователь вводит в поля генератора для подготовки документа (в том числе ФИО, адрес, телефон, сведения о транспортном средстве, VIN и реквизиты документов), обрабатываются программным кодом непосредственно в браузере пользователя. В текущей версии сервиса содержимое этих полей не направляется Оператору, не записывается Оператором в базу данных и не сохраняется Оператором после закрытия страницы.

Не следует вводить в свободные поля сведения, которые не требуются для формирования выбранного документа.

3. Цели и состав данных

Цель локальной обработки введённых пользователем сведений — автоматическая подстановка данных в выбранный шаблон, отображение сформированного документа и предоставление возможности его копирования, печати или сохранения на устройстве пользователя. Состав сведений зависит от конкретного генератора и ограничивается полями, показанными пользователю.

4. Правовые основания

При использовании функций, для которых требуется обработка персональных данных, основанием является волеизъявление пользователя и, когда это необходимо, отдельное согласие на обработку персональных данных. Согласие предоставляется отдельно от Пользовательского соглашения.

5. Срок обработки и удаление

Данные, введённые в поля локального генератора, используются в рамках текущей сессии страницы. Пользователь может удалить их с экрана, очистив форму или закрыв страницу. Оператор не располагает копией содержимого локально сформированного документа, если пользователь самостоятельно не направит его Оператору иным способом.

6. Хостинг GitHub Pages

Сайт размещён на инфраструктуре GitHub Pages. При посещении сайта технические сведения о соединении, включая IP-адрес, могут обрабатываться GitHub в соответствии с правилами и политикой конфиденциальности GitHub. Такая техническая обработка инфраструктурой хостинга не означает передачу GitHub содержимого полей локального генератора со стороны Оператора.

7. Передача третьим лицам

В текущей версии сервиса Оператор не передаёт третьим лицам содержимое полей генератора. Если в дальнейшем появятся серверное сохранение, личный кабинет, отправка документов, внешние API, аналитические или иные функции, затрагивающие введённые данные, настоящая Политика и соответствующие формы согласия подлежат актуализации до запуска таких функций.

9. Безопасность
