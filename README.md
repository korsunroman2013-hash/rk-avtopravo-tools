# RK Автоправо Tools

Набор веб-инструментов проекта **«Роман Корсун | Автоправо | ПДД»** для автомобилистов.

## Первый проект

### Помощник по перерегистрации транспорта в новых регионах

Цель — сделать интерактивный сервис, который задаёт пользователю несколько вопросов о транспортном средстве и помогает определить подходящий порядок дальнейших действий.

План первой версии:

- регион и вид регистрации автомобиля;
- дата регистрации;
- имеющиеся документы;
- сведения о собственнике;
- предварительный результат;
- список документов и ссылки на подробные материалы сайта.

> Важно: результат помощника носит информационный характер и не заменяет индивидуальную юридическую консультацию.

## Структура

- `registration-helper/` — интерактивный помощник по перерегистрации;
- в дальнейшем здесь появятся другие калькуляторы и сервисы проекта.
